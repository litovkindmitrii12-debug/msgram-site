Когда можно будет скачать Msgram?

Установочные файлы ещё готовятся. Дата выпуска пока не объявлена. Как только появится готовая версия, в разделе загрузок будет доступна ссылка для соответствующей платформы.

Для каких устройств будет мессенджер?

Планируются версии для Windows, Linux и Android. Точные системные требования и поддерживаемые версии ОС будут опубликованы вместе с релизом.

Переписка на сайте — это уже приложение?

Это интерактивный концепт для знакомства с идеей Msgram. Он не показывает фактический интерфейс или подтверждённые возможности приложения. Демо работает в вашем браузере и ни с кем не связывается.

Куда отправляются сообщения из демо?

Никуда. Они остаются в памяти этой страницы и исчезают после её обновления. Демо не подключено к серверу, не создаёт аккаунт и не сохраняет переписку.
