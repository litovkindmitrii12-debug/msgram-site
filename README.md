# Msgram — сайт

Статичный сайт для GitHub Pages (без сборки).

## Публикация
1. Создайте репозиторий на GitHub и загрузите все файлы из этой папки в корень.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)`.
3. Сайт появится на `https://<ваш-ник>.github.io/<репозиторий>/`.
   Если назвать репозиторий `<ваш-ник>.github.io`, адрес будет короче: `https://<ваш-ник>.github.io/`.

## Когда появятся файлы
Загрузите сборки в GitHub Releases и впишите ссылки в начале `script.js` (объект `DOWNLOADS`).
Кнопка автоматически станет рабочей, плашка «Скоро» исчезнет.
