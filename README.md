# Msgram

Адаптивный русскоязычный сайт мессенджера Msgram. Чистые HTML, CSS и JavaScript, без сборки, зависимостей и внешних запросов. Использован предоставленный владельцем логотип. Кнопки загрузки Windows, Linux и Android отключены до появления файлов.

## Посмотреть

Откройте `index.html` в браузере. Интерактивная переписка — концепт для сайта, а не скриншот реального приложения. Сообщения существуют только в памяти текущей страницы и исчезают после обновления.

## Опубликовать на GitHub Pages

1. Создайте репозиторий GitHub, например `msgram`.
2. Загрузите **содержимое** этой папки в корень репозитория. `index.html` должен находиться в корне.
3. Самый простой вариант: в **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/(root)**. Сохраните.
4. После публикации адрес будет вида `https://ВАШ-ЛОГИН.github.io/msgram/`. Точный адрес покажет GitHub в разделе Pages.

Также приложен автоматический workflow `.github/workflows/pages.yml`. Если используете его, в Settings → Pages выберите **GitHub Actions** вместо публикации из ветки. Workflow запускается при изменениях в `main` или вручную. Для загрузки через веб-интерфейс скрытую папку `.github` можно не добавлять, если выбран вариант публикации из ветки.

## Включить скачивание

В начале `script.js` замените `null` у нужной платформы на URL релиза в кавычках:

```js
const downloads = {
  windows: 'https://github.com/ВАШ-ЛОГИН/msgram/releases/download/v1.0/Msgram.exe',
  linux: null,
  android: null,
};
```

Это пример адреса, его нужно заменить на реальный. Ссылка платформы станет активной автоматически. После появления релизов обновите тексты о разработке в `index.html` (включая `release-note`, верхнюю строку платформ и метаданные). Реальные возможности, требования к ОС и политика конфиденциальности пока не предоставлены, поэтому сайт не обещает шифрование, звонки, синхронизацию или другие неподтверждённые функции.

## Файлы

- `index.html` — содержание и структура.
- `styles.css` — оформление и мобильная адаптация.
- `script.js` — локальное демо и будущие ссылки на загрузку.
- `assets/msgram-logo.jpg` — оригинальный логотип.
- `.github/workflows/pages.yml` — необязательная публикация через Actions.

## Дизайн

Оригинальная композиция Msgram: тёмный фон, синий акцент из логотипа, системный шрифт Segoe UI, крупные заголовки, сетка с адаптацией под смартфоны. Кнопки реагируют коротким переходом 180 мс. При `prefers-reduced-motion` движение отключено. Есть видимый клавиатурный фокус, ссылка пропуска навигации, подписи полей и семантические секции.

Использованные материалы:

- [Taste Skill](https://github.com/leonxlnx/taste-skill) — композиция, типографика, проверка текстов.
- [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) — поиск системы оформления, доступность и адаптация.
- [Awesome Design MD](https://github.com/voltagent/awesome-design-md) — референс Linear: иерархия тёмных поверхностей и тонкие границы. Это библиотека справочников, а не устанавливаемый навык.
- [Design Motion Principles](https://github.com/kylezantos/design-motion-principles) — сдержанный отклик кнопок и поддержка reduced motion.

Сайт подготовлен для публикации. Репозиторий GitHub и публичный адрес автоматически не создавались.
